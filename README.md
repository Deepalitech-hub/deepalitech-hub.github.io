# Neon Cherry Blossom — Deepali Dewangan's Portfolio

A responsive interactive portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open `index.html` with the Live Server extension, or open `index.html` directly in a browser.

## Replace your photo or resume
- Profile image: replace `assets/profile.jpg` with your image (keep the same filename).
- Resume: add your current PDF as `assets/resume.pdf`. The resume buttons already point to this path. A real resume PDF is not included yet.

## Contact form
The form opens the visitor's default email application with a prefilled message to deepalidewangan58@gmail.com. It does not send messages directly from the website.

## Notes
